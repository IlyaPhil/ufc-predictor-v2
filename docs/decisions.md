# Принятые решения

Журнал решений, принятых вместе с пользователем. Перед тем как предлагать альтернативу —
проверьте, не обсуждалась ли она здесь; пересматривать имеет смысл только с новыми аргументами.

| 2026-10-26 | ufcstats брать через CSV-зеркало Greco1899, а не напрямую | сайт закрыт JS-проверкой от ботов; обходить защиту не стали | решать proof-of-work в скрейпере |
| 2026-10-26 | Сопоставление имен: не угадывать, спорное — в ручные алиасы с обоснованием | ошибочно связанный бой портит историю двух бойцов незаметно | нечеткий поиск с порогом |
